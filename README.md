# Nerdópoles

Protótipo inicial do menu do Nerdópoles, jogo web/PWA do ecossistema Nerdora.

## v0.1
- Menu travado usando a arte oficial fornecida pelo projeto.
- Sem funções de botões nesta etapa.
- Experiência orientada para modo retrato.
- PWA instalável com service worker e cache offline do menu.
